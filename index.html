The six release rules

1
Fₜ < VcConservation release
2
Iₜ < Qf and Vc ≤ Fₜ < VeQuadratic low-inflow release
3
Iₜ < Qf and Fₜ ≥ VeRelease equals Qf
4
Iₜ ≥ Qf and Vc ≤ Fₜ < VfLinear high-inflow release
5
Iₜ ≥ Qf and Vf ≤ Fₜ < VeAdditional flood release
6
Iₜ ≥ Qf and Fₜ ≥ VeRelease equals inflow

Scientific disclaimer and independent visualisation

Scientific disclaimer. This interactive panel visualises the reservoir release-rule relationships described for LISFLOOD v5.0. The numerical settings and curves are illustrative calculations, not observed reservoir releases, forecasts or validated simulations of reservoir behaviour. The reservoir animation does not simulate storage changes through time. The precise equations, including the Rule 5 coefficient k, require verification against the relevant LISFLOOD implementation before use as scientific evidence.
